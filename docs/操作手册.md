# 像素时钟 · 表盘斗图库 操作手册

> 适用设备：ESP32-S3 N16R8 + HUB75 64×64 像素时钟（接入家庭 WiFi，NTP 自动校时）  
> 配套文档：`docs/dial-library.md`（库清单 / 来源 / 维护手册）  
> 版本：2026-10-25（固件 v0.3.6，修正 v0.3.5 缓冲位写反导致的全屏闪·调亮度零闪烁+确认按钮）

---

## 一、这是什么

这是一块 64×64 像素点阵时钟，连上家里的 WiFi 后自动从网络校时，**表盘上的时间永远是实时时间**。

- 表盘库里现在有 **58 个表盘**，都存放在设备自身存储里，**不依赖固件**，加表盘不用重刷机。
- 每个表盘要么是动画（循环播放），要么是静态图，带时钟的表盘会在画面上叠加当天的 `时:分`（部分还有方块数字样式）。
- 用手机或电脑浏览器就能操作，不需要装 App。

---

## 二、怎么打开操作页面

1. 让**手机/电脑和时钟连同一个 WiFi**（同一台路由器）。
2. 打开浏览器，访问：
   ```
   http://192.168.1.50/
   ```
   若打不开，可试 `http://pixelclock.local/`（mDNS 名）。
3. 页面自上而下分四块：
   - **顶部**：固件自带表盘按钮（出厂时钟面等）。
   - **「屏幕亮度」卡片**：拖动滑块或点预设即可调亮度（见流程 5）。
   - **中部「表盘斗图库」**：58 个表盘缩略图网格，这是本手册的主角。
   - **底部**：上传区（维护者给库里加新表盘用，普通使用用不到）。

> ⚠️ 设备 IP 是路由器分配的，**可能变化**（比如重启路由器后）。若 `192.168.1.50` 打不开，去路由器后台查名为 `pixelclock` 的设备当前 IP，或用串口看开机日志里的 `IP:`。

## 三、操作流程

### 流程 1 · 换一个表盘上屏（最常用）

| 步骤 | 操作                           | 说明              |
| -- | ---------------------------- | --------------- |
| 1  | 浏览器打开 `http://192.168.1.50/` | 见第二节            |
| 2  | 下滑到「表盘斗图库」                   | 58 个缩略图，每个下方有标注 |
| 3  | **点一下任意缩略图**                 | 设备立刻把该表盘上屏      |
| 4  | 看顶部提示 `✓ 已上屏「xxx」`           | 即切换成功           |

缩略图下方小字含义：

- `静态` = 单帧不動；`12帧 @10fps` = 12 帧动画、每秒 10 帧；`整分钟顶金币` = 每分钟整点触发一次动画。
- `· 时钟` = 经典 HH:MM 叠加；`· 方块时钟` = 马里奥问号块数字叠加。

> 默认勾选了「存 flash 开机自启」（网格标题右侧），所以你换上的表盘**下次开机自动播放**，不用每次手动切。

---

### 流程 2 · 调整时钟的位置 / 大小 / 颜色

每个**带时钟**的表盘，缩略图**右上角有个 ⚙ 齿轮**。点它即可微调时钟叠加层，改动会永久保存到设备。

**打开与预览**

1. 点 ⚙ → 弹出「时钟叠加层」对话框。
2. 里面是一张 64×64 实时预览：当前表盘 + **此刻的真实时间**，所见即所得。

**移动时钟位置**（两种方式任选）

- **直接点图**：在预览图上点一下，时钟跳到你点的位置（经典模式定位文字中心，方块模式定位小时块）。
- **方向键微调**：用 ▲ ▼ ◀ ▶ 每次移动 1 像素，适合精细对齐。

**切换两种时钟样式**

- **经典 HH:MM**：白字 + 黑描边 + 底部黄色秒进度条。
  - `字号`：1 或 2（2 更大更醒目）。
  - `前景色`：**白 / 黑 / 黄**三选一——浅色背景的表盘（如皮卡丘、拉布拉布、疯狂动物城）务必选**黑**，白字会看不见。
- **方块数字**：马里奥问号块风格，7×7 大字显示时/分，固定黑字。
  - 两个色块（小时块 / 分钟块）作为一个整体移动，位置用上面的点图或方向键调。

**保存与还原**

- 改满意后点 `保存` → 提示 `✓ 叠加层已保存，下一帧生效`，若表盘正在播放立即生效，并写回设备存储。
- 想重来点 `重置` → 回到该表盘的默认位置/样式。

> 小提示：调的时候表盘最好正在上屏（先点缩略图上屏，再点它的 ⚙），改完保存能立刻在实体屏上看到效果。

---

### 流程 3 · 设为开机自启

两种方式，效果一样：

- **自动**：流程 1 切换表盘时，网格标题右侧「存 flash 开机自启」默认勾选，切上去就自动存了。
- **手动**：上屏后页面会自动执行存 flash；也可把勾去掉后再手动触发一次切换以更新。

设备重启（断电再上电）后会从存的表盘启动。

---

### 流程 5 · 调节屏幕亮度

页面「屏幕亮度」卡片可调。注意：**拖动滑块只改数字，不会实时改屏**——必须点「应用亮度」或点预设才会推送（避免拖动时误触发屏闪）；改动会自动保存（断电不丢）。

> **为什么之前会闪 / 现在怎么修的**：面板是双缓冲，DMA 一直在交替扫描两块缓冲。亮度接口 `setBrightness8` 会重写缓冲的 OE 亮度掩码——**只要重写的正好是「当前正在扫描的那块」，当前帧就被撕裂成一次闪**。v0.3.4（单次直写）仍会闪，v0.3.5 进一步把缓冲位写反（把前台当后台写）导致**全屏乱闪**。v0.3.6 修正：写亮度时**始终只写「后台缓冲（没在扫的那块，即 `back_buffer_id`）」→ 翻转让新亮度无撕裂上屏 → 补写新后台**，DMA 全程只扫带新亮度的缓冲，**调亮度零闪烁**。

| 步骤 | 操作                           | 说明               |
| -- | ---------------------------- | ---------------- |
| 1  | 浏览器打开 `http://192.168.1.50/` | 见第二节             |
| 2  | 找到「屏幕亮度」卡片                   | 在固件表盘按钮下方        |
| 3  | **拖动滑块**选好亮度，再点「✓ 应用亮度」       | 屏上亮度按设定值变化       |
| 4  | 或点预设（暗/中/亮/最亮）一键应用            | 一步到位，等同先填值再应用   |
| 5  | （可选）看顶部提示 `✓ 亮度 N`           | N 为 0–255 的目标亮度值 |

- 滑块范围 **0–255**：`0` 关闭（屏全黑），`15` 极暗夜用，`55` 为出厂默认值（柔和），`120` 明亮，`200` 最亮。
- 点预设会**一步到位**：🌙 暗=15、☀ 中=55、🔆 亮=120、💡 最亮=200。
- 设的是「**日间目标亮度**」：**夜间息屏时段**（默认 23:00–07:00）会临时压到很暗的 `12`，那是自动省电行为，白天仍按你设的值亮。

> 小提示：夜间把亮度调到 15 以下，屏幕几乎不刺眼，适合卧室。

---

### 流程 4 ·（维护者）往库里加新表盘

普通使用不需要，留给折腾表盘的人。完整链路见 `docs/dial-library.md` 第三节，概要：

1. **取素材**：从源项目提取/渲染出 64×64 帧序列（GIF / PNG / 编辑器渲染）。
2. **转格式**：脚本把帧序列包成 `dials/<名字>.rgb565` + `meta.json`（帧率、是否叠时钟、位置/颜色）。
3. **上传设备**：
   ```bash
   python tools/upload_dials.py --only <名字>
   ```
   分片上传 + 校验，传完刷新页面即见，不用重编固件。
4. **验证**：`/diallist` 看是否在列；`/dialplay?name=<名字>` 上屏；串口监控无崩溃。

## 四、参数速查表

时钟叠加层参数（对应固件 `gOv*` 与 `/dialov` 接口）：

| 参数      | 经典模式 (mode 0)            | 方块模式 (mode 1) | 说明      |
| ------- | ------------------------ | ------------- | ------- |
| `ox`    | `-1`=水平居中；否则 0–57 为文字左 x | 0–45 小时块左上 x  | 水平位置    |
| `oy`    | 0–50 文字上 y               | 0–45 块左上 y    | 垂直位置    |
| `ox2`   | 忽略                       | 0–45 分钟块左上 x  | 方块模式专属  |
| `scale` | 1–2 字号                   | 忽略（固定 7×7）    | 经典模式字号  |
| `fg`    | 0 白 / 1 黑 / 2 黄          | 忽略（固定黑）       | 经典模式前景色 |
| 秒进度条    | 底部黄色 2px                 | 无             | 经典模式专属  |

屏幕亮度参数（对应固件 `/brightness` 接口，持久化到 NVS）：

| 参数      | 范围    | 说明                                                  |
| ------- | ----- | --------------------------------------------------- |
| `level` | 0–255 | 目标亮度；`/brightness?level=N` 设置并保存；`/brightness` 读当前值 |
| 夜间息屏    | 固定 12 | 23:00–07:00 自动压低，覆盖手动设置（省电）                         |

边界规则（超出自动钳制，不会跑出屏）：

- 经典模式：`ox∈[-1,64]`、`oy∈[0,50]`、`scale∈[1,2]`、`fg∈[0,2]`。
- 方块模式：`ox/oy/ox2 ∈ [0,45]`（块 19×19，分钟块默认 `ox2=34`）。

## 五、常见问题（FAQ）

**Q1：浏览器打不开 `192.168.1.50`？**

- 确认手机/电脑和时钟在**同一个 WiFi**。
- IP 可能变了：去路由器后台查 `pixelclock` 设备，或看设备开机串口日志的 `IP:`。
- 确认设备已通电、WiFi 已连上（屏幕应有内容而非全黑）。

**Q2：缩略图是空白/灰的？**

- 页面缩略图是分批加载的（每次 3 张排队），**等几秒**会自动出来，不是故障。

**Q3：时钟在浅色表盘上看不清（白字透明）？**

- 点该表盘 ⚙ → 经典模式把 `前景色` 改成 **黑 (fg=1)** → 保存。皮卡丘 / 拉布拉布 / 疯狂动物城这类浅底表盘出厂已设黑字，不用再改。

**Q4：我调了位置/颜色，屏上没变化？**

- 确认弹窗提示 `✓ 叠加层已保存`，且**该表盘正在上屏**（先点缩略图上屏，再点 ⚙ 调）。
- 方块模式没生效？检查 `ox/oy` 是否在 0–45 内（越界会被钳掉）。

**Q5：想恢复某个表盘的默认时钟位置？**

- ⚙ 对话框里点 `重置` 即可还原。

**Q6：怎么让时钟显示成方块数字（马里奥风）？**

- ⚙ 里切到「方块数字」模式（标注 `· 方块时钟` 的表盘默认就是这种；其它表盘也能手动切，但经典表盘的背景不一定预留了块位，可能需要自己挪位置）。

**Q7：断电后我换的表盘没了？**

- 没勾「存 flash 开机自启」就不会存。重新点一下该表盘上屏（默认勾选即自动存）即可。

**Q8：亮度调到很亮/很暗后断电，下次还是这个值吗？**

- 是的。亮度设置写入设备存储（NVS），断电不丢，下次上电沿用。
- 但**夜间 23:00–07:00** 会自动降到很暗（12），那是省电息屏，白天仍恢复你设的值，属正常现象。

**Q9：调亮度时屏幕会闪吗？**

- v0.3.4 起不会。每次调亮度只做一次亮度写入（单次直写），不再有连闪。若看到极短「一帧」的亮度跳变，那是数值本身变化，属正常非故障。早期固件（≤v0.3.3）因走爬升连写会连闪，请升级到 v0.3.4。

- 其中**角色 IP**（马里奥、皮卡丘、Hello Kitty、疯狂动物城、宝可梦等）均为厂商版权，**仅限个人把玩，禁止商用或再分发**。

- 设备连的是你家 WiFi，操作页面**仅在局域网内**可达，外网无法访问。

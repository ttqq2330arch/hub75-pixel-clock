# 多板部署指南（固件 0.3.1+）

> 适用：你想做**好几块**像素时钟，且希望每块都能稳定打开网站、互不打架。
> 关键事实：**同一个局域网里，一个 IP / 一个 mDNS 名只能对应一台设备**。
> 两块板都叫 `pixelclock.local` 会抢名（表现就是"有时打不开网址"）。
> 所以正确做法是：**每块板给独立名字 + 固定 IP**，内容与界面则完全共用（同一份固件、同一套表盘）。

---

## 1. 命名与地址规则

| 板 | mDNS 名（手机访问） | 固定 IP（全平台访问） | MAC |
|---|---|---|---|
| 原板（第一套） | `pixelclock-01.local` | `192.168.1.50` | *见下方"待补"* |
| 新板（第二套） | `pixelclock-02.local` | `192.168.1.52` | `c4:9e:7e:01:50:08` |
| 第三套 | `pixelclock-03.local` | `192.168.1.53` | 烧录后从 `/status` 或 `PixelClock-Setup` 看 |
| … | `pixelclock-0N.local` | `192.168.1.5N` | 同上 |

- **手机/平板**：直接开 `http://pixelclock-0N.local/`（iOS/Android 原生支持 mDNS）。
- **Windows 电脑**：`.local` 需要 Bonjour（装一下 iTunes 或 Bonjour 打印服务即可）；嫌麻烦就直接用 IP `http://192.168.1.5N/`，**IP 在所有设备上都通**。

---

## 2. 给每块板烧同一份固件（0.3.1）

固件烧录**只写 bootloader / partitions / firmware 三个分区，不碰文件系统**——所以：
- 已经在板上的 58 个表盘不会被清掉；
- 之后改名字也不用重刷固件。

```
cd hub75-pixel-clock
python tools/flash_firmware.py COM17      # 把 COM17 换成当前板的串口号
```
烧录时板子必须只有一块接着电脑（避免烧错）。串口号在设备管理器里看（CH343 = 新板，CH340 = 旧板）。

---

## 3. 连 WiFi（仅"全新空板"需要）

- 新板首次上电、没有 WiFi 凭据时会自己开热点 **`PixelClock-Setup`**（无密码）。
- 手机连这个热点 → 浏览器开 `http://192.168.4.1/` → 填**家里的 WiFi 名称 + 密码** → 保存。
- 板子重启后自动连上你家路由器，屏上会显示它分到的 IP。

> 如果这块板之前已经连过 WiFi（比如从别处搬来的），凭据在 NVS 里会保留，跳过这步。

---

## 4. 设独立名字（每块板做一遍）

板子连上 WiFi 后，从**手机或电脑**对它发一条命令即可（用它的当前 IP）：

```
curl -X POST "http://192.168.1.5N/setname?name=pixelclock-0N"
```

- 名字限字母/数字/连字符，长度 1..31，例如 `pixelclock-02`。
- 命令执行后板子写盘并**自动重启**；重启完，`/status` 里的 `host` 字段就是新名字，mDNS 名变为 `http://pixelclock-0N.local/`。

验证：
```
curl "http://192.168.1.5N/status"     # 看返回的 "host":"pixelclock-0N"
```

---

## 5. 路由器绑定固定 IP（强烈建议）

名字解决"抢名"，**固定 IP 解决"地址变来变去"**。在路由器里按 MAC 绑定：

1. 登录你家路由器管理页（通常是 `192.168.1.1` 或路由器背面写的地址）。
2. 找到 **DHCP 静态分配 / 地址保留 / 静态租赁**（各家叫法不同）。
3. 把每块板的 MAC 绑到上表里规划的固定 IP（如 `c4:9e:7e:01:50:08` → `192.168.1.52`）。
4. 保存后，板子重启或重连都会稳定拿同一个 IP，永不再变。

做完后：每块板 = **固定 IP（全平台可用）+ 独立名字（手机用）**，内容和界面完全一致，互不冲突。

---

## 6. 推送表盘到新板

名字设好、IP 固定后，把全套表盘推过去（不重刷固件）：

```
cd hub75-pixel-clock
python tools/upload_dials.py --ip 192.168.1.5N
```

会按 `tools/dial_collection/dials/` + `out/` 的 meta 把 58 个表盘（含 15 个 ClockWise Plus、浅底表盘黑字等）全量上传。

## 7. 待补：第一套（原板）的收尾

第一套目前仍是旧固件（0.3.0）+ 默认名 `pixelclock`，且本次会话中它离线未接。
要做齐"多板不冲突"，需对它同样处理：
1. 把它接上电脑，烧 0.3.1 固件（表盘不动）；
2. `curl -X POST "http://192.168.1.50/setname?name=pixelclock-01"`；
3. 路由器把它的 MAC 绑到 `192.168.1.50`。
完成后第一套也变成 `pixelclock-01.local`，与 `pixelclock-02` 彻底互不抢名。
